# 素材与许可

| 素材 | 来源 | 许可 |
|---|---|---|
| 配音 | Kokoro-82M v1.1-zh（hexgrad），男声 zm_010，本机合成 | Apache-2.0，可商用 |
| 字体 | 思源宋体 / 思源黑体（Noto Serif CJK、Noto Sans CJK） | SIL OFL 1.1，可商用 |
| 地图轮廓 | Natural Earth 1:50m 陆地数据，只画陆地轮廓，不画国界 | 公有领域 |
| 纸张纹理、印章、拓片颗粒 | `src/make_assets.py` 程序生成 | 自制 |
| 插画（二桃杀三士、面碗、椅子、毛笔、锁、拔河小人、日历、报纸与公文版面） | 页面内 SVG / CSS 自绘；汉画像石只是仿其风格，未使用任何拓片图像 | 自制 |
| 配乐与音效 | `src/build_audio.py` 用 numpy 合成（拨弦、低音、钟、盖章声） | 自制 |
| 照片 | 未使用任何照片 | — |

裁决书、呈文、《苏报》《甲寅》等版面都是**据文字重排**，不是原件影像，片中已在画面上注明。

另：最初试过 CosyVoice-300M-SFT 的“中文男”（Apache-2.0），在本机 CPU 上合成后用语音识别回听，咬字清晰度明显不如 Kokoro（拼音匹配度 0.92 对 0.98，且有三句疑似漏读），因此成片改用 Kokoro。
