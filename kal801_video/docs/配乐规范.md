# 配乐规范（所有视频通用，粘进每个 prompt 的「配乐」一节）

> 原路径 /mnt/project-files/videos/prompts/配乐规范.md 在本云端容器中不存在，此文件按用户消息中贴出的全文保存。

目标：雄浑、悲壮、能代入，但永远托着旁白，不抢旁白。观众应该"感觉到"音乐，而不是"听见"音乐。

## 一、按题材选情绪

- 战争、守城、英雄末路（兵法、孤城、刘裕、韦孝宽一类）：低音弦乐长音铺底 + 大鼓/太鼓 + 埙或箫或古琴做主音色。小调，慢速（60–80 BPM）。悲壮靠低音和留白，不靠密集旋律。
- 人物命运、历史转折（李斯、麋芳、章士钊一类）：大提琴独奏或古琴 + 弦乐铺底，克制、略带苍凉。
- 思想、心理、哲学（荣格、龙场、韦伯、托克维尔一类）：钢琴 + 柔和弦乐 pad，温暖、安静，像在书房里听人讲。
- 商业、组织、AI、交易（黄仁勋、维修工、海龟一类）：低调电子脉冲或极简钢琴 + 轻打击，有推进感但不"打鸡血"。
- 冷战、悬疑（阿尔希波夫一类）：低频 drone + 稀疏的心跳式低鼓，紧张但不吵。

## 二、跟着故事起伏，不要一首曲子铺到底

每条视频至少分三层：
1. 铺底：开场到交代背景，音乐很轻，只有长音或 pad。
2. 推进：冲突升级时加入鼓或节奏，音量略抬。
3. 高潮：决战、牺牲、反转那一刻上全编制。这里旁白停 1–2 秒，让音乐单独出来一下，这是最能让观众代入的地方。
结尾：音乐收成单个乐器或余音，留 2–3 秒再黑场。

段落之间用 2–4 秒交叉淡化衔接，不要硬切，不要让人听出循环。

## 三、音乐从哪来（按优先级）

1. 本地 AI 生成：用 MusicGen（transformers 里的 facebook/musicgen-stereo-medium 或 large）。按每一层分别生成 20–30 秒片段，再交叉淡化拼接。提示词示例：
   - 悲壮战争：`epic cinematic orchestral, low cellos and double basses, slow taiko drums, chinese xun flute melody, solemn, tragic, heroic, D minor, 70 bpm, no vocals`
   - 思想类：`warm intimate piano with soft strings pad, reflective, calm, slow, no drums, no vocals`
   - 商业类：`minimal modern electronic pulse with soft piano, steady, thoughtful, 90 bpm, no vocals`
   每层生成 2–3 版，挑最好听、最不抢人声的一版。
2. 免版税曲库（下载得到就用）：Pixabay Music（免署名）、Kevin MacLeod / incompetech（CC BY，需在简介里署名）。
3. 都不行：导出一版「无配乐」成片，发布时用视频号自带音乐库加，音量拉到 15–25%。

禁止：影视/游戏原声、有歌词的歌、任何来路不明的版权音乐。

## 四、混音（最关键，决定"舒服"）

- 旁白整体响度 -16 LUFS，真峰值不超过 -1.5 dBTP。
- 音乐在有旁白时比人声低约 15–18 dB；旁白停顿时自动回升（侧链压缩）。
- 音乐削掉 2–4 kHz 一点（-3 到 -4 dB），给人声让出清晰度。
- 开头淡入 2 秒，结尾淡出 3 秒。
- 参考 ffmpeg（voice.wav 为旁白，music.wav 为拼好的配乐）：

```
ffmpeg -i voice.wav -i music.wav -filter_complex "[0:a]asplit=2[v][sc];[1:a]volume=0.5,equalizer=f=3000:t=q:w=1:g=-4,afade=t=in:d=2[m];[m][sc]sidechaincompress=threshold=0.02:ratio=10:attack=15:release=500[duck];[v][duck]amix=inputs=2:duration=first:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=11" mix.wav
```

## 五、导出前自检

- 用手机外放听一遍完整成片：每句话都听得清，音乐没有哪里突然冒出来。
- 加了配乐后重跑一次 ASR，误读率不能比纯人声明显变差。
- 高潮那一段单独再听一遍：有没有"起鸡皮疙瘩"的感觉，没有就换一版音乐或把留白拉长。
