## 声音

- 引擎：Qwen3-TTS-12Hz-1.7B-Base ICL 克隆（Apache-2.0）。没有用 edge-tts、云扬、云健、云希、Kokoro，没有任何整句变调或音高拉伸。
- 参考音：爆款分支 `claude/ai-diversity-tyranny-mob-9t217y` 里的 `samples/voice_candidates/candidate_seed33_89.8Hz.mp3`（VoiceDesign seed 33，15.76 s，本机复测中位 90.0 Hz）。没有重新设计音色，没有用托克维尔那期的 A0b / voice_design_reference.m4a。
- `--ref-text`：「一九零六年，英国普利茅斯的一个牲畜展览会上，有人办了一场猜牛重量的比赛。将近八百个人，各自写下自己的答案，谁也看不见别人写了什么。」
- 运行环境：本次云端容器没有 GPU，所以和爆款那次一样在 CPU 上跑（bf16，4 线程）。脚本已改成有 CUDA 时自动用 GPU，音色和门控参数不变。

## 流程（复用爆款脚本）

1. `narrate_batch.py`：全片批量合成，每批 4 句，最多 5 轮换 seed（seed 5000 起）。门控：去掉多余停顿后中位音高在 86.5–103.5 Hz 之间，faster-whisper large-v3 回读按拼音加声调比对，错误率 ≤ 5%。第一遍 113 句合成 137 次，只有 line_0002 音高略低（85.1 Hz）没过门控。
2. `postprocess.py`：停顿压到 ≤ 0.4 s；rubberband 拉速并保留共振峰，旁白目标 5.4 字/秒，引文目标 4.3 字/秒，最大 ×1.32；50 Hz 高通；人声有效段 RMS 拉到 −18 dBFS；后期后再跑一遍 ASR。
3. `redo_lines.py`（本期新加，引擎、参考音和门控不变）：后期后音高离开 86.5–103.5 Hz，或后期 ASR 对不上的句子，只重做那一句。每个候选都在内存里走一遍完全相同的后期，要求原始和后期两个版本都过音高门控，并且后期 ASR 错误率为 0。重做过的句子：0002 0009 0011 0019 0020 0035 0037 0043 0083 0104 0112 0113，全部尝试合计 183 次。
4. `assemble.py`：重采样到 48 kHz；每句尾部补零到整毫秒，所以 timeline 的时间是精确值；句间插 0.40 s 静音后拼接；整轨一次性增益 +8.17 dB，再过一个 4 倍过采样、3 ms 前瞻、60 ms 释放的纯增益真峰值限幅器（不削波，峰值最多压 8.9 dB），校准到 −15 LUFS / ≤ −1.5 dBTP。逐句 wav 保持后期电平（有效段 −18 dBFS），没有套用整轨增益。

## 结果

- `narration.wav`：517.724 s（8 分 37.7 秒），**−15.02 LUFS integrated，真峰值 −1.80 dBTP**，LRA 1.9 LU。用 ffmpeg loudnorm 和 ebur128 两种方式复测，结果一致。
- 中位音高（在交付的 48 kHz 逐句文件上测，parselmouth 自相关）：**最低 86.9 Hz、中位 92.8 Hz、最高 101.3 Hz**。113 句全部落在 85–105 Hz 内，而且都在 86.5–103.5 Hz 余量内。
- 拉速：中位 ×1.146，最大 ×1.32。旁白语速中位 5.40 字/秒；三句引文分别为 4.31、4.30、4.32 字/秒。
- line_0002「大胆一点，宏伟一点。」：10 次合成里，原始音高最高只到 86.2 Hz，比原始门控低 0.3 Hz。后期后交付文件为 87.8 Hz，已经在 85–105 Hz 和 86.5–103.5 Hz 范围内。ASR 回读正确。
