## 配音

- 托克维尔声音：Qwen3-TTS-12Hz-1.7B-Base ICL 克隆，在云端 CPU 上生成（无 GPU，约 5.5 倍实时）。
- 参考音频：取自分支 `claude/tocqueville-america-video-a250yg` 的 `tocqueville_video/preview/voice_design_reference.m4a`（18.08 秒，ASR 回读与该分支 tts_clone.py 里的参考文本一致）。**它应与 box 上的 A0b 同源，但不是那个 −15 LUFS 文件本身**；若要与 box 版逐字节一致，可用 `sentences.json` 在 box 上重配。
- 每句检查：中位音高须在 82–108 Hz、语速 2.8–7.5 字/秒，不过就换 seed（最多 3 次）。118 句全部入区间。
- 后处理：去头尾静音、句内停顿压到 ≤0.38 秒、rubberband R3 变速 1.175 倍（保共振峰）、50 Hz 高通。
- ASR 回读（faster-whisper small，按无调拼音比对）：全片错误率 0.9%，0 句超阈值。「大悦」首轮被读成近似「大域」，已用同音字「大越」只送 TTS 重配那一句（字幕仍是「大悦」）；「大长秋」同理用「大常秋」送 TTS。
- `sentences.json`（含 tts_text / subtitle / 起止秒）、`sentences.txt`、`narration.srt` 供 box 重配后回传对时；`旁白干声_托克维尔.m4a` 是本片使用的干声。

## 配乐与音效

全部用 numpy 现场合成，没有用任何曲库或第三方音频：低音太鼓式鼓点、弦乐铺底（Dm–B♭–F–C）、Karplus-Strong 古琴拨弦、低频持续音；钩子是更鼓（两声鼓＋梆子）接一记重棒击（风声＋低频闷响＋脆响），同样的棒击用在两次「打死」和「一棒一棒」处；章节标题处一声低鼓。分段：钩子鼓弦 → 出身弦乐 → 求评古琴 → 五色棒鼓弦 → 后路弦乐 → 演义古琴 → 收束弦乐渐强。没有打字声、没有铃铛。

## 史料核对

所有上屏引文已在本次会话里重新对维基文库原文（《三国志》卷1/6/32、《后汉书》卷8/37/67/68/69/78、《三国演义》第1/4回）。比简报新增、均已核：

- 桥玄「君未有名，可交許子將」「太祖乃造子將，子將納焉，由是知名」——裴注引《世语》（本集「缺名」的直接证据，放进了钩子）。
- 「嵩靈帝時貨賂中官及輸西園錢一億萬，故位至太尉」——《后汉书·宦者列传》。
- 曹腾保举种暠：「今身爲公，乃曹常侍力焉」——同上。
- 第二次党锢「百餘人，皆死獄中」——《后汉书·党锢列传》。
- 「郡國率二十萬口歲舉孝廉一人」——《后汉书·丁鸿传》。
- 西园八校尉，蹇硕为上军校尉、「雖大將軍亦領屬焉」，曹操典军校尉、袁绍中军校尉——《后汉书·何进传》、《灵帝纪》注引《山阳公载记》。即被打死叔父的蹇硕后来成了曹操的上司。
- 《让县自明本志令》「自以本非巖穴知名之士」「違迕諸常侍……故以病還」——裴注引《魏武故事》（曹操自认起步缺名）。
- 济南相「奏免其八」——《武帝纪》正文。
- 演义对照：第一回许劭评语后是「操聞言大喜」；蹇硕之叔「就棒責之」（史书是「即殺之」）；「操父曹嵩，本姓夏侯氏」。第四回献刀。

需要知道的处理：

- 简报写《让县自明本令》，片中用通行全名《让县自明本志令》。
- 「公元一七四年前后」由「生于155年」（建安二十五年卒，年六十六）加「年二十」推得，所以写「前后」。
- 北部尉只讲「京城北边一片的治安官，管巡夜、抓盗贼、查夜禁」，没有给秩级数字。
- 「为什么伤不了他」：史书没说，片中明说「这只是推测」。
- 刘备与曹操：只讲《英雄记》孤证，标「孤证」，并指出与《武帝纪》「至陳留，散家財」对不上；没有说少年相识。
- 类比只比结构，不涉及任何当代群体、机构；没有使用当代军政职务名称。
- Spence 1973 只借机制，片中标「只借用机制」。方诗铭的观点没有用。
