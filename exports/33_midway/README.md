## 自检结果

- **配音**：托克维尔声音。Qwen3-TTS-12Hz-1.7B-Base 用 ICL 克隆参考音色（Tocqueville 分支的 `voice_design_reference`，18.08 秒），在 CPU 上用 bf16 逐句合成，共 140 句。
  - 每句中位音高都在 82–108 Hz 之内。
  - rubberband R3 加速 1.05 倍（保共振峰），合成速度约 248 字/分（含停顿）。
- **ASR 回读**（faster-whisper small，按拼音比对）：
  - 单句：平均误差 1.0%。
  - 成片音轨按时间线切句：平均误差 1.1%。
  - 超过 8% 的 6 句都是阿拉伯数字写法差异（「10点10分」对「十点十分」）或同音字（暖好机/暖好击、那/的），没有读错。
- **响度**：成片 −15.4 LUFS integrated，真峰值 −2.3 dBTP（无配乐版 −15.4 / −2.2）。
- **底乐**：本片原创编配，D 小调，84 bpm，用鼓、圆号、铜管、弦乐和定音鼓。
  - 用 FluidSynth 和 FluidR3_GM 音色库（MIT 许可）渲染，可商用。
  - 有旁白时比人声低 21 dB，旁白停顿处抬 4.5 dB。
- **音画同步**：恒定 25 fps，混音时加了 `aresample=async=1`。
  - 视频流 849.720 s，音频流 849.706 s，相差 0.014 s。
  - 开头（8.3 s）、中段（439.3 s）、结尾（832.5 s）各抽一帧，字幕都和正在读的句子一致。
- **开场**：
  - 首帧：云层、俯冲的美机、三艘日军航母，标题「命运的五分钟 / 可能根本不存在？」。
  - 声音钩子：第 0 帧战鼓，接俯冲呼啸，再接三声爆炸，和画面闪白对齐。
  - 没有黑场、片头 logo、打字音效或求关注提示。
- **合规**：
  - 称「日军」；不出现旭日旗或任何旗帜，没有人物肖像，不涉及中国战场，不做当代类比。
  - 地图标「示意」，右上角有「AI 配音」角标。
