# 成片规格与自检（2026-11-25 实测）

| 项 | 要求 | 实测 |
| --- | --- | --- |
| 画幅 / 帧率 | 1080×1920，恒定帧率 | 1080×1920，25 fps 恒定 |
| 时长 | 建议 10–12 分钟 | 10:00.4 |
| 文件大小 | < 100 MB | 有配乐版 92.4 MB；无配乐版 91.4 MB（H.264 两遍 1095 kbps + AAC 128k） |
| 音画同步 | 音频加 aresample=async=1，音视频流时长差 ≤ 0.1 s | 两版均 v=600.400 s / a=600.454 s，差 0.054 s |
| 开头 / 中段 / 结尾对齐抽查 | 字幕与配音对齐 | ASR 词级时间戳 vs 字幕起点：3.68/3.69、8.58/8.53、18.10/18.11；305.30/305.37、309.98/310.01、312.66/312.70；589.74/589.91 s（差 ≤ 0.2 s） |
| 响度 | 约 -15 LUFS，真峰值 ≤ -1.5 dBTP | 有配乐版 -15.4 LUFS；无配乐版 -15.3 LUFS；混音母带 TP -1.5 dBTP |
| 底乐电平 | 比人声低约 20–24 dB | 说话段实测低 20.0 dB；开头 3 秒让磬声露出 |
| 底乐授权 | 免版权或自己生成 | 本工程 numpy 原创合成（古琴式拨弦、磬、箫、低音铺底），无第三方素材 |
| 声音钩子 | 结合主题，不用打字声、小铃铛、求关注提示 | 第 0 帧一声磬；无打字音效、无求关注提示 |
| 首帧 | 最强画面 + 第一句钩子，无黑场/片头 | 第 0 帧：夜医院走廊、靠墙闭眼的护士剪影 + 标题；第一句旁白 0.5 s 开始 |
| 配音 | 托克维尔音色（Qwen3-TTS 克隆） | Qwen3-TTS-12Hz-1.7B-Base ICL 克隆托克维尔设计参考音（18 秒），CPU 合成；109 句中位音高 83–99 Hz（6 句略低于 85 Hz，最低 82.4） |
| 语速 | 约 255 字/分 | 2473 字 / 10:00 ≈ 247 字/分（全片统一 rubberband 1.10 倍，保共振峰） |
| ASR 回读 | 逐句对稿 | faster-whisper medium，按无调拼音：全片 0.6% 差异，均为同音字或数字写法；修正重配 3 句（「心不厌没」误读 méi → 改读 mò；「量」→「测」；「这位父亲，不只是陪着哭」断句） |
| AI 标识 | 画面角标 + 平台声明 | 右上角常驻「AI 配音」；发布时勾选含 AI 生成内容 |
| 示意标注 | 脑区、曲线、类比 | 脑区图标「示意」；情绪曲线标「示意：只画变化方向，非原始数据」；水墨落水标「类比示意」 |

已知小瑕疵：个别长句字幕会切出很短的一屏（如「小悲」），不影响理解；如需可调 `render.py` 的 `chunks()` 合并阈值后重渲（约 20 分钟）。
