# 史实核对（选题 70 · 左将军与煮酒论英雄）

原文全部于 2026-11-25 对维基文库原文逐字比对（`action=raw` 抓取《三國志》卷一、卷六、卷三十二、卷三十五，《易傳·繫辭下》）。上屏用通行繁体（「爲」统一作「為」），未改字。

## 一、与简报不同的地方（按原文改）

| 简报写法 | 原文 | 处理 |
| --- | --- | --- |
| 左将军「位次上卿」【待核】 | 本会话未能读到《续汉书·百官志》《汉书·百官公卿表》原文（维基文库限流，ctext 反爬） | **按规则删去**。片中只说「以天子名义正式授予的高级将军名号，有印，有绶」，依据是《先主傳》「上還所假左將軍、宜城亭侯印綬」 |
| 「遂殺徐州刺史車冑」（作《先主传》） | 《先主傳》作「先主乃殺徐州刺史車冑，留關羽守下邳，而身還小沛」；「遂殺」出自《武帝紀》「至下邳，遂殺徐州刺史車冑」 | 古文卡用《先主傳》原句 |
| 「198 年投靠曹操」 | 《武帝紀》把「呂布襲劉備，取下邳。備來奔」系于建安元年（196）；《先主傳》：吕布袭下邳后，刘备屯小沛，又被吕布攻击，才「敗走歸曹公」。建安三年（198）高顺破沛后，刘备随曹操东征 | 片中说 196 年丢徐州、随后投曹；198 年下邳之围 |
| 「刘备此时已参与衣带诏密谋，所以才失匕箸」 | 《先主傳》顺序：董承受密诏 →「先主未發」→ 曹操说「天下英雄」→ 失匕箸 →「遂與承……同謀」 | 片中说「刘备被卷了进来」，饭后「正式结成了同谋」；曹操的用意「史书没有交代，不替古人下结论」 |
| 「两年前他刚丢了徐州」 | 徐州 196 年失守，左将军 199 年 | 改为「前几年」，并点明妻儿两次被俘（196 吕布、198 高顺） |
| 两军「相持一个多月」 | 「先主與術相持經月」 | 改为「一个来月」 |
| 诸葛亮「开口第一句」 | 「將軍既帝室之冑，信義著於四海」在隆中对中段 | 改为「为他分析天下大势，说的是」 |
| 「袁术在寿春称帝」 | 《袁術傳》有「遂僭號」，同卷可证其据寿春，但未写称帝地点 | 片中只说「袁术干脆自己称了帝」 |
| 现代类比「战区司令级的上将衔」 | 补充裁定：不得用当代中国军政职务名称 | 改为「国家正式授予的上将军衔，却没有防区、没有部队、没有指挥部」 |

## 三、演义对照与校正（片中已讲）

- 煮酒论英雄：正史只有一句话加失匕箸；雷声出自裴注引《华阳国志》；「青梅煮酒」「以龙喻英雄」是《三国演义》。
- 刘曹早年相识：只有裴注引《英雄记》一条孤证（灵帝末年同回沛国募兵），与《武帝纪》「至陳留，散家財」起兵不合；「少年同学」无任何史料。曹操少年时的朋友是袁绍（《袁紹傳》「太祖少與交焉」）。
