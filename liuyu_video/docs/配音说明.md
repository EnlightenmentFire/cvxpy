## 1. 声音设计
- 描述：「四十多岁男中音，醇厚偏低沉，历史纪录片旁白，凝重克制，语速中等偏慢」
- 参考文本：「公元四零四年的春天，长江边上的京口城，天还没亮。有些事情，史书只写了一句，却改变了此后两百年的走向。」

| 候选 | 中位音高 | 时长 |
|---|---|---|
| seed 11 | 77.5 Hz | 18.0 s |
| seed 22 | 76.9 Hz | 13.2 s |
| seed 33 | 86.5 Hz | 16.2 s |
| **seed 44（选用）** | **91.6 Hz** | 15.7 s |

先出的 3 个都离 90 Hz 偏远，所以加了 1 个，选最接近 90 Hz 的 seed 44。

## 2. 克隆与逐句校验
做法：
- 克隆用 ICL 模式，参考音加参考文本一起送进去。
- 每句再按引文切段：引文慢读，引文前两三个字的引子并进引文，人名不单独切出来。

每段要过三道检查，不过就换 seed 重来（最多 5 次）：
1. **音高**：用 parselmouth 测中位音高。整句要在 85–105 Hz，不过关就重做偏离最大的那一段。全程没有做变调。
2. **ASR 回读**：Whisper 回读，Paraformer 复核。按无调拼音和期望读音比对，相似度要 ≥ 0.9，所以同音字不算错。
3. **关键词**：京口、建康、刘裕、桓玄、北府、王谧、刁逵等必须读对。

后期处理：
- 停顿超过 0.4 秒的压到 0.4 秒（全片只有"两万人，一下子垮了"之后留了 1.6 秒，给高潮音乐）。
- 50 Hz 高通。
- 每句统一到 −18 dBFS RMS。
- 配乐侧链压低、整体响度 −16 LUFS / 真峰值 −1.5 dBTP，见《配乐说明》。

样音里发现「骰子」被读成了 shǎizi（色子），正式版改为「投子」，读 tóuzi。

**终版复查时发现并修掉的一处错读**：替换表里原来写的是"替他还钱""悄悄还的"，和改稿后的原句（"替他还了钱""替他还的"）对不上，这两处的"还"没有被替换。
- s2f"钱是王谧悄悄替他还的"：Whisper 和 Paraformer 都听成"替他**怀**的"，确认读错。
- s2e"替他还了钱"：这里读 hái 还是 huán，ASR 都会写成"还"，查不出来，所以一并重做。
- 顺带把只靠声调区分、ASR 查不出的两处也改成单音字："一箭正中"（zhòng）、"王谧为公"（wéi）。

做法（`fix_seg2.py`）：
- 只重做这四句里对应的那一段，每段 6 个 seed，两路 ASR 都要读对，音高在 85–105 Hz。
- 选中的新段用一次 rubberband（保共振峰）拉到和旧段完全相同的时长再拼回去，所以整句和整片时间轴一帧都没动。
- 重做后又把替换表里每个键和稿子逐条核对过：现在每个键都能在稿子里找到原样子串；"江乘""句章"只出现在地图上、不在旁白里，保留无害。

## 4. 1 分钟样音结果（开场 → 第一章《魏书》那句）
整句中位音高：

| 行 | 中位音高 | 行 | 中位音高 |
|---|---|---|---|
| s0a | 101.3 Hz | s1a | 88.0 Hz |
| s0b | 85.4 Hz | s1b | 97.3 Hz |
| s0c | 85.7 Hz | s1c | 88.6 Hz |
| s0d | 99.0 Hz | s1d | 100.0 Hz |
| s0e | 94.8 Hz | | |

- **9 句全部在 85–105 Hz。**
- 21 个片段中有 20 个在片段层面过关。"这个人，后来当了皇帝"这一段 5 个 seed 都在 78–84 Hz，但整句在范围内，所以保留。
- 混音后整段回读：Whisper 0.995，Paraformer 0.97–0.995。
- **关于"京口"**：Whisper 常把它听成"金口"，用 Kokoro（音素明确是 jing）读的版本也一样被听错；Paraformer 两种都识别成"京口"。所以关键词检查以"任一 ASR 读对"为准。耳听如果觉得偏 jin，请告诉我，我换参考音。
