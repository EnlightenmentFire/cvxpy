# 配乐说明（按《配乐规范》重做）

## 来源与授权
- **没用 MusicGen**：规范第三节首选它，但 `facebook/musicgen-stereo-medium` 和 `-large` 的权重是 **CC-BY-NC 4.0（禁止商用）**，和配音规范里"只用可商用的开源模型"冲突。
- **改用 ACE-Step 1.5**，同样是本地 AI 生成：
  - 许可证是 MIT。
  - 模型卡写明生成的音乐可以商用，训练数据是授权曲目、公有领域或免版税音乐，以及 MIDI 合成数据。
  - 只用了 DiT turbo（8 步），没用它的语言模型。
- 片中没有影视/游戏原声，没有带歌词的歌，也没有来源不明的素材。

## 题材与分层
题材属于"战争、守城、英雄末路"（规范里点名的刘裕一类）。配器是低音弦乐长音铺底，加太鼓，主音色用埙或古琴。全片 D 小调，60–72 BPM。

| 层 | 用在哪里 | 提示词要点 |
|---|---|---|
| 铺底 | 开场 → 第三章 | 大提琴、低音提琴长音，零星的埙，古琴泛音；不要鼓；64 BPM |
| 推进 | 第四章"等" → 覆舟山 | 低音弦乐固定音型，慢太鼓，定音鼓滚奏，埙的旋律；72 BPM |
| 高潮 | 覆舟山放火 → 对比表 | 全编制，太鼓群，低音铜管，埙领奏；72 BPM |
| 回落 | 恩怨 → 寒人 | 低音弦乐长音，很轻的远处鼓心跳，零星古琴；60 BPM |
| 尾声 | 收尾三句 → 黑场 | 埙独奏，长混响，弦乐余音渐弱；60 BPM |

每层都一次生成整段（铺底 190 秒、推进 150 秒、高潮 45 秒、回落 95 秒、尾声 32 秒），所以没有循环。层与层之间用 3 秒等功率交叉淡化。高潮片段最响的 3 秒，对准"两万人，一下子垮了"之后旁白停的 1.6 秒。

成片里的排布（层间各有 3 秒交叉）：

| 层 | 成片时间 | 画面内容 |
|---|---|---|
| 铺底 | 0:00 – 2:32 | 开场 → 第三章 |
| 推进 | 2:29 – 4:20 | 第四章"等" → 覆舟山布阵 |
| 高潮 | 4:17 – 5:02 | 放火、溃散 → 对比表；4:52.1–4:53.7 旁白空白，音乐最响的 3 秒就落在这里 |
| 回落 | 4:59 – 6:14 | 恩怨 → 寒人 |
| 尾声 | 6:11 – 6:27.5 | 收尾三句 → 片尾卡；旁白 6:20.9 结束后埙的余音约 6 秒，最后 3 秒淡出，1.2 秒黑场 |

## 混音链（规范第四节，侧链参数按实测调过）
```
[0:a] 旁白：50 Hz 高通，每句 -18 dBFS RMS → asplit → [v][sc]
[1:a] 配乐（分层排布 + 3 秒推子跟随 + 逐句电平，见下）→ acompressor(阈值 -12 dB, 2:1, 只削峰) → volume=0.5
      → equalizer f=3000 q=1 -4 dB → afade 淡入 2 秒 / 淡出 3 秒 → [m]
[m][sc] sidechaincompress=threshold=0.05:ratio=4:attack=15:release=700 → [duck]
[v][duck] amix normalize=0 → loudnorm I=-16 : TP=-2.0 : LRA=11
```

真峰值目标从规范的 −1.5 改成 −2.0：成片音频是 AAC 128k，实测 −1.5 dBTP 的 WAV 编码后会升到 −1.3 dBTP，超出规范。留 0.5 dB 余量后，成片解码实测见文末。

## 侧链参数（实测后调整）
- **规范参考值**：threshold 0.02、ratio 10、release 500 ms。在这条人声（−18 dBFS RMS）上实测，讲话时音乐被压下 25–30 dB，比规范要求的 15–18 dB 深得多。要拉回 15–18 dB，停顿时音乐就得响过人声。
- **最终参数**：先给配乐加"推子跟随"，按 3 秒窗口把电平拉向各层目标值，最多 +8 / −10 dB。侧链改为 threshold 0.05、ratio 4、attack 15 ms、release 700 ms。
- **实测（推进到高潮段，0.4 秒窗口）**：讲话时人声比音乐高中位约 17 dB；停顿时音乐回升到约 −21 dBFS。

## 逐句电平（终版复查后加）
**发现的问题**：按逐句拆开量，全片中位 16.6 dB 掩盖了两头的偏差。
- 第六章高潮段，音乐只比旁白低 9.9–13.3 dB。全片最要紧的那句「谦等士卒多北府人，素畏伏裕，莫有斗志」（s6f）只低 9.9 dB。
- 第四、五章推进层有几段反而低了 25–29 dB，几乎听不见。
- 原因：侧链对每一层压下去的量基本一样（跟人声电平走，不跟音乐电平走），所以压之前更响的高潮层，在人声底下也更响。
- 另外句内短停顿时侧链一松，鼓点、铜管会冒上来。最严重的一处是 4:57.7"这说明什么？"之后，音乐瞬间和人声一样响。这正是规范说的"突然冒出来"。

**做法**（`mix2.py` 的 `level_to_voice`）：
1. 每句测一次真实结果：跑同一条 ffmpeg 链路，用 K 加权 400 ms 量这句人声的整体响度和压低后的音乐。
2. 按差值给这句的配乐补增益，目标是低 16.5 dB。冷开场按规范"很轻"，目标 21 dB。增益曲线句间插值、1.5 秒平滑，几轮收敛。
3. 天花板：句内和句间不到 0.8 秒的空隙里，音乐最多升到比这句人声低 9 dB。
4. 0.8 秒以上的空白（章节转场、片名卡、片尾）不设天花板。高潮那 1.6 秒空白在侧链回升之外再抬 5 dB。

| 指标（K 加权 400 ms） | 之前 | 现在 |
|---|---|---|
| 逐句中位差值（56 句） | 9.9–36.8 dB，5 句低于 15 dB | 16.4–16.9 dB；冷开场 21–25 dB |
| 第六章 s6d–s6g2 | 9.9–13.3 dB | 16.4–16.5 dB |
| 句内音乐最接近人声的一刻 | 最近 −0.4 dB（顶过人声），12 句不到 8 dB | 最近 8.5 dB，没有一句不到 8 dB |
| 讲第六章关键句时的音乐 | −27.1 LUFS | −33.0 LUFS |
| 高潮 1.6 秒空白里的音乐 | −16.4 LUFS | −17.5 LUFS（人声中位 −16.9，音乐在这里和人声一样响） |

两处偏离目标都在冷开场：s0a、s0c 那几秒配乐本身几乎是空的，补满 +12 dB 也只到比人声低 23–25 dB。规范要求开场"很轻"，所以没有再硬抬。

## 成片实测（终版，`final_check.py` + 成片 mp4 解码）
| 项目 | 规范要求 | 实测 |
|---|---|---|
| 整体响度 | −16 LUFS | 混音 WAV −16.0 LUFS；成片 AAC 解码后 −16.1 LUFS；LRA 2.5 LU |
| 真峰值 | ≤ −1.5 dBTP | 混音 WAV −2.0；**成片 AAC 解码后 −1.8 dBTP** |
| 讲话时人声高出音乐 | 15–18 dB | **逐句中位全部 16.4–16.9 dB**（冷开场 21–25）；全片所有讲话窗口的中位 15.9 dB |
| 侧链恢复 | 停顿时音乐回升 | 句内短停顿最多回升到比人声低 9 dB；0.8 秒以上空白自由回升 |
| 高潮空白 | 1–2 秒，音乐单独出来 | 空白 1.6 秒，音乐升到和人声一样响（−17.5 LUFS，人声中位 −16.9），比讲话时的音乐高约 15 dB |
| 逐句 ASR（57 句，取 Whisper/Paraformer 较高者） | 加音乐后不明显变差 | 纯人声均值 0.9977 / 混音 0.998 / 模拟手机外放 0.998（逐句电平之前是 0.9977 / 0.9976 / 0.998）；最低一句 0.949（s8a 手机外放：两路都把"京口"听成"金口"，Paraformer 还把"门阀"听成"文法"；这句纯人声也只有 0.974） |

- 量法说明：之前调参时写的"约 17 dB"是推进到高潮这一段、0.4 秒 RMS 窗的结果。这里统一用广播通用的 EBU 瞬时响度（K 加权、400 ms 窗）。
- 若按 50 ms 不加权 RMS 统计，中位是 19.2 dB；那种窗太短，会把字与字之间的小空隙也算进去。
- 模拟手机外放的做法：混音转单声道，再加 300 Hz 高通和 7 kHz 低通，然后跑同样的两路 ASR。
