# 配乐说明（按配乐规范重做）

## 音乐来源

规范第三节的首选是本地 AI 生成（MusicGen），这一版没有用 AI 音乐，原因：

- **MusicGen（facebook/musicgen-stereo-medium / large）的模型权重是 CC-BY-NC 4.0，限非商业使用。** 这和配音规范第 8 条（只用可商用的开源模型）冲突，所以没有用。
- 可商用的替代是 **ACE-Step 1.5**（MIT 许可，模型卡写明生成的音乐可商用，训练数据为授权曲库、免版税曲库和合成数据）。它的推理代码在 GitHub 上，安装运行它被本会话的权限规则拦下了（不是项目里的代码），需要你点头才能装。
- 所以这一版的配乐全部是**代码合成**（numpy 振荡器、滤波、混响），不涉及任何外部音乐或模型，版权上没有问题。音效同样是合成的。

## 分层结构（冷战/悬疑：低频 drone + 稀疏的心跳式低鼓）

| 段落 | 层 | 内容 |
|---|---|---|
| 冷启动（假想） | 合成器主题 | 80 年代合成器：脉冲低音、琶音、领奏；开头淡入 2 秒；画面定住后转为长音 pad；白闪时合成器“断电”般停下 |
| 片名 → 第 2 章前半 | 铺底 | 低频 drone，只有长音 |
| 第 2 章“盾 + 矛”起 → 第 5 章 | 推进 | drone + 稀疏心跳低鼓（每两拍一次“咚-咚”）+ 极低的脉冲贝斯；第 3 章假想段插入合成器，回到现实时切断 |
| 第 6 章 雷克雅未克 | 高潮 | 钟表滴答 + 轻弦乐，逐渐加厚；“最后卡住的，只是一个词：实验室”之后**旁白停 2 秒**：约 0.2 秒后全编制涌出（定音鼓式重击 + 低音弦乐和弦 + 铜管式长音），单独出来约 1.5 秒，最响处比旁白高约 5 LU；下一句开口前 0.3 秒压回去，回落到弦乐 |
| 第 7 章 | 假想合成器 → 现实 drone | 苏联假想激光站用暗色合成器；发射时切回现实，火箭轰鸣、翻滚长音（音效） |
| 第 8 章 | 收束 | 柔和弦乐长音，无鼓 |
| 结尾 | 余音 | 放慢变暗的合成器主题 → 最后一个钟声般的单音，留 2–3 秒余音，画面 2 秒淡出到黑 |

段落之间用 2–4 秒交叉淡化；只有“假想 → 现实”的白闪处故意让合成器切断（原始需求里的设计），后面接混响尾音，不是硬切到静音。

## 混音（成片文件实测）

- 整片响度 **−16.0 LUFS**，响度范围 2.3 LU；真峰值在 AAC 编码后实测 **−2.1 dBTP**（无配乐版同样是 −16.0 LUFS、−2.1 dBTP），都低于 −1.5 dBTP 的上限。
  - 做法是 ffmpeg 两遍 loudnorm。旁白的峰值超出了纯线性增益能容纳的范围，所以第二遍实际用的是 loudnorm 的动态模式，由它的真峰值限制器压住峰值。实测增益基本不随时间变化：0.5 秒窗口里，90% 的时间在 +0.34 到 +0.98 dB 之间。
  - 高潮里定音鼓这类尖峰，编码后会再升约 1.2 dB，所以编码前把峰值压到 −3.5 dBTP（无配乐版 −3.0）。
- **音乐比人声低多少**（逐句计算，只算有声音的帧，音乐 + 音效一起算）：
  - 中位数 **17.0 dB**，最小 15.2 dB，没有一句低于 15 dB；
  - 只有第 6 章第一句（k1）是 20.5 dB：那里音乐本来就轻，是渐强的起点。
- **侧链**（检测人声，自动压低音乐）：
  - 说话时压低音乐。
  - 句间停顿（不超过 0.4 秒）不放开，避免音乐一句一句地“喘气”。
  - 超过 1 秒的空档（章节之间、片名、高潮、片头片尾）：人声停下 0.15 秒后放开，0.35 秒内回升；下一句开口前 0.3 秒提前压回，不会被第一个字切断。
- 高潮最响处瞬时响度 −10.9 LUFS，旁白中位数 −15.9 LUFS，高 4.9 LU。这是全片最响的一刻，但不至于让人去调音量。
- 音乐在 3 kHz 处削 4 dB（Q=1），给人声让出清晰度。
- 音乐开头淡入 2 秒、结尾淡出 3 秒；画面最后 2 秒淡出到黑。
- 里根原声（档案录音很轻、峰值很尖）提到和旁白一样的响度时，加了前视限幅器，不会削波。
- **加配乐后的 ASR 回读**（规范：不能比纯人声明显变差）：
  - **逐句识别**（每句从纯人声和成片音轨的同一位置切出来，单独识别）：3147 个音节里，纯人声错 2 个（0.06%），成片错 3 个（0.10%）。纯人声的 2 个是“谈”写成同音的“弹”；成片多出的 1 个是把“舒尔茨”写成另一种译名“舒尔兹”，意思不变。见 `final/asr_lines.txt`。
  - **整片连续识别**（成片文件）：0.30%。Whisper 的长音频模式每次分段都不一样，这个数在几次重混之间从 0.25% 到 0.37% 不等。多出来的差异是：漏掉“换句话说”“那么”，以及把前文的“火箭表现完美”又插进了一句。这几句在逐句识别里都读对了。见 `final/asr_film.txt`。
- 另出一版**无配乐成片**（只有人声和音效），发布时可以用视频号音乐库配乐，音量拉到 15–25%。

## 这一版修正了什么

1. **侧链检测改为按立体声实际播放电平测量。** 原来先混成单声道再测，宽立体声的合成器被低估了最多 3 dB。结果第 7 章和片头第一句的音乐只比人声低 12–13 dB，不到规范要求；现在每句都在 15.2–18 dB。
2. **高潮。** 原来人声停下后，侧链要约 1.3 秒才放开，“实验室”之后的全编制只露出约 0.8 秒，就被下一句压下去了。现在短停顿不放开、长空档及时放开，音乐能单独出来约 1.5 秒。
3. **里根原声。** 有几个峰值在中间文件里被削波（16 位整数格式）。现在加了前视限幅器，中间文件改存浮点。
