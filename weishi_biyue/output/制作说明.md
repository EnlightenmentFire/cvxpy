## 成片自检结果

**ASR 回读**（faster-whisper medium，按带声调拼音比对）

- 纯人声：0 处读错。
- 成片混音后：0 处读错。
  - 「壶关」被写成「湖关」，两字同为 hú 二声，读音没错。
  - 「一千八百」被写成「1800」，只是 ASR 输出数字的格式，不是读错。

**响度**

- 整体 −16.5 LUFS，真峰值 −1.92 dBTP（AAC 编码之后测，要求不超过 −1.5）。
- 有旁白时，音乐比人声低约 11.6 dB（中位数），在 10–12 dB 的目标内。

**连播三遍的首尾接缝**

- 接缝处没有样点突变，不会「咔」一下。
- 结尾长和弦的电平（−26 dB）和开头配乐的电平一致，都是 D 小调。

**画面**

- 答案落下之前，没有任何一段超过 3 秒完全不动。
- 字幕和所有文字都在安全区内：上面让开 10%，下面让开 20%。

**敏感词**

- 旁白、字幕、竹简、角标、封面都逐字过了一遍。
- 人名只有曹操、曹仁，地名只有壶关。
- 「活埋」在旁白里出现一次，字幕里出现一屏。画面里没有任何伤亡表现。

## 完播自审

1. **只看第一秒，知不知道在问什么？** 知道。第 1 帧就是三行大字「包围敌人 / 为什么要故意 / **留个口子？**」，下面就是一座被围得严严实实的城，没有黑场。
2. **关掉声音只看字幕，看得懂吗？** 看得懂。字幕覆盖全部旁白，共 8 屏。「谁、在哪、下了什么令、结果怎样、谁劝的、劝完怎样」都能从字幕读出来。答案是大字，出处也在画面上。
3. **没学过的人，答案落下时会不会「哦」一下？** 会。铺垫是「越围越打不下」：城头光点越撞越亮、越密。之后画面定住，抛出「曹仁劝的，是什么？」，空 0.7 秒，埙只吹一句。重鼓和金色光路同时落下，答案正好是前面那个画面的反转。
4. **「待核」各条**都已对照《三国志》和《十一家注孙子》原文核实，没有要拿掉的内容。高幹当时已离城，守城的是他手下的将领，旁白本来就不提守将。

## 配乐是怎么来的

所有声音素材都由本机生成，没有用任何曲库素材。

- **主乐**：MusicGen（`facebook/musicgen-stereo-medium`），用您给的提示词出了 3 版，选了第 1 版（seed 7）。选它有两个原因：
  - 只有它是 D 小调、123 BPM；第 2 版是降 B 小调，第 3 版是 117 BPM、调性含糊、起伏也平。
  - 它的能量落在人声主频带（1–4 kHz）里的只有 3.6%，最不抢人声。
- **分轨**：用 Demucs（MIT 许可）把主乐拆成鼓和弦乐两轨，然后按画面节点重新编排：
  - 0 秒：弦乐直接中等强度进入，鼓只留一点。
  - 4.5 秒：鼓加到一半。
  - 「全部活埋」这一下，乐队整个抽空。这样既有冲击力，也让「埋」的二声听得清：不抽空的话，ASR 会把它听成「卖」。
  - 8.4 秒：鼓全开砸回来，五次箭头撞墙都落在拍子上。
  - 缺口出现时：鼓收一半，弦乐长音按 D→F→A 一级级往上走。
  - 「曹仁劝的，是什么？」时：鼓回满，往上顶。
  - 18.95 秒：全部切掉，只剩一个 A 长音，再加一句埙（同一模型生成的独奏，D4 一跃到 A4，落在属音上）。
  - 19.62 秒：重鼓，比人声早 90 毫秒，避开侧链压缩。接着 D 小调长和弦一直托到最后一帧，不淡出，结尾只留 15 毫秒防咔哒。
- **混音**：按您给的 ffmpeg 链做（音量 0.72，3 kHz 衰减 4 dB，开头淡入 0.3 秒，侧链压缩参数 threshold 0.03 / ratio 6 / attack 10 / release 300）。响度用两遍 loudnorm（线性模式）做到 −16 LUFS，真峰值目标设为 −2.0 dBTP，给 AAC 编码留余量。

## 复现

源码在 `weishi_biyue/src/`，按下面的顺序跑：

| 步骤 | 脚本 |
|---|---|
| 设计音色 | `vd.py`、`vd2.py` |
| 逐句克隆 | `clone.py` |
| 挑选、拼接配音 | `voice_build.py` |
| 生成画面时间轴 | `make_timeline.py` |
| 渲染帧 | `render_frames.py`（场景代码在 `scene.py`） |
| 编排配乐 | `music_arrange.py` |
| 混音 | `mix.py` |
| 编码 | `encode.sh` |
| 自检 | `qa.py` |
| 封面 | `cover.py` |

运行时用到的数据（句子、时间轴、逐字时间戳、配音候选报告、配乐参数、自检结果）都在 `weishi_biyue/data/`。
