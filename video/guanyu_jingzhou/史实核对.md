# 史实核对与取舍说明

底本：维基文库《三国志》（含裴松之注）卷 1、9、14、17、32、35–41、45、47、54、57、58，《资治通鉴》卷 68–69。
片中每条引文都在画面引文卡上标了层级：**正史**（《三国志》正文）／**裴注**（裴松之注所引）／**通鉴**／**后人论说**／**解读**。演义情节一概不用。

## 一、按原文改动了提纲的地方

| 提纲原说法 | 原文 | 片中处理 |
|---|---|---|
| “军资不悉相及” | 《关羽传》作“芳、仁供给军资，**不悉相救**”；“不悉相及”是《资治通鉴》卷 68 的文字 | 旁白读《关羽传》原文，引文卡加校记“《通鉴》作不悉相及” |
| 傅士仁 | 《关羽传》《吕蒙传》《吴主传》《杨戏传》均作“**士仁**”，《通鉴》作“傅士仁” | 全片称“士仁”，首次出现加校记 |
| 麋芳“地位高却长期不掌兵” | “未尝有所统御”说的是哥哥**麋竺**（《麋竺传》：安汉将军，“班在军师将军之右”）。麋芳是南郡太守，守江陵，“与关羽共事” | 人物卡里把兄弟二人分开写清 |
| 麋芳是刘备“大舅子” | 原文只说麋竺“进妹于先主为夫人”，麋芳是竺弟；他与麋夫人谁长谁幼无记载 | 只说“姻亲” |
| “袭取沿江烽燧” | 《吕蒙传》正文是“至羽所置**江边屯候**，尽收缚之”；“烽火不及举”出自裴注引《吴书》的虞翻书信 | 画面标“屯候（江边哨所）”，灯火逐一熄灭 |
| 辱求婚使者 | 在《关羽传》**正文**（“羽骂辱其使，不许婚”），不是裴注 | 标正史。裴注《典略》“貉子”一段裴松之本人已驳，不用 |
| “足兵足食” | 《诸葛亮传》作“**足食足兵**” | 按原文 |
| 虞翻劝降士仁、“蒙以仁示之” | 出自《吕蒙传》**裴注引《吴书》**；《虞翻传》正文只有“南郡太守麋芳开城出降” | 标裴注，并附正文一句 |

## 二、超出教科书版本的几处（均有原文）

1. **想降的只有麋芳一人**：《虞翻传》“今区区一心者麋将军也，城中之人岂可尽信……时城中有伏计，赖翻谋不行。”
2. **后方三个管事的都与关羽不和**：麋芳、士仁之外，荆州治中潘濬“典留州事，亦与关羽不穆”（《杨戏传》载《季汉辅臣赞》注）。
3. **粮食问题贯穿始终**：军资“不悉相救”；俘于禁数万人后“托以粮乏，擅取湘关米”，这正是孙权出兵的口实（《吕蒙传》）。
4. **诸葛亮原本就是荆州管后方的人**：“使督零陵、桂阳、长沙三郡，调其赋税，以充军实”；建安十六年“亮与关羽镇荆州”，十九年与张飞、赵云入蜀（《诸葛亮传》《赵云传》）。
5. **蜀人自己的复盘**：廖立“后至汉中，使关侯身死无孑遗，上庸覆败，徒失一方”（《廖立传》）。
6. **能制住刘备的是法正**：“法孝直若在，则能制主上，令不东行；就复东行，必不倾危矣”（《法正传》）。
7. **时间跨度**：八月水淹七军（《武帝纪》）— 闰十月吕蒙袭江陵（《吴主传》“闰月”）— 十一月陆逊取宜都（《陆逊传》）— 十二月关羽被擒（《吴主传》）。中间有闰月，近五个月。

### 史料互歧处

- 麋芳、士仁的投降：《关羽传》说“权阴诱芳、仁，芳、仁使人迎权”，像是早有约定；裴注引《吴书》说士仁“拒守”、麋芳“城守”，经虞翻劝说、“以仁示之”才降；裴注引《吴录》又说麋芳因失火被责而“潜相和”，“以牛酒出降”。片中开城一场按《吴书》，同时在公安一场用字幕补出《关羽传》“阴诱”一句。
- 关羽的死地：《关羽传》作“临沮”，《吴主传》作“章乡”（临沮境内）。片中说“临沮”，地图标“章乡”。
- 法正卒年：《法正传》只说“明年卒，时年四十五”，未言死因，片中只说“去世”。

## 三、“解读”部分的边界

- 片中从“以下是解读”起到第五章结束，画面右上常驻“解读”标记。
- “史书里找不到成都向荆州派兵的记载”是**默证**：史书无载不等于必无其事，片中只陈述“无载”。
- “荆州派／东州派／益州派”三分不是史书原有的说法。田余庆《李严兴废与诸葛用人》用的是“新人／旧人”“客／主”二分，三分法是后人细化。结构图上已注明“属今人归纳”。关羽籍贯河东，严格说属“元从”而非荆州士人，图中把他单列在“荆州”框里。
- 不同看法：陈寿评“羽刚而自矜……以短取败”；章太炎《訄书·正葛》“不惜以荆州之全土假手于吴人，以陨关羽之命”（借刀说）；方诗铭等赞成并把主谋改为刘备；朱绍侯斥为有“厚诬古人”之嫌；田余庆《〈隆中对〉再认识》“问题不在于刘备之弃荆州，而在于荆州之不得不弃”。
- **刘仲敬**：只查到一篇无期数、无日期、标“来源：网络”的转载问答，其中并未专门谈关羽失荆州，也没有“荆州集团被牺牲”一类原话。出处无法核实，**全片未引用**。
- 田余庆、章太炎、朱绍侯的引文系据网络可见的转引核对（多处一致），未能逐一对纸本页码，如要用于正式出版请再核。

## 四、地图与数字

- 成都—江陵直线距离约 780 公里，按今地经纬度计算。
- 地形用真实高程数据渲染；城邑位置取通行考证的今地近似值。古今河道不同（尤其荆江段与洞庭湖），河流走向为今河道示意。
- 屯候的具体位置、湘关的确址史无明文，画面均标“示意”。水淹七军的淹没范围按高程推算，仅为示意。
- 势力范围色块为示意，不代表精确边界。
