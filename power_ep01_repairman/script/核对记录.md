# 史料与引文核对记录（v2）

处理原则：原书核到的，照原书说；只有二手文献的，片中标“转述/概括”；推出来的，标“推论”；核不实的，删掉或改成更保守的说法。

## 一、理论来源：已对原文核实

| 内容 | 原文出处 | 片中处理 |
|---|---|---|
| “Uncertainty itself does not give power: coping gives power.” | Hickson, Hinings, Lee, Schneck & Pennings, ASQ 16(2), 1971, **p. 219**（原文就是冒号；作者把它当作对克罗齐耶的修正提出） | 英文原句上屏并朗读，中文字幕翻译 |
| 难以替代：“a department may hold on to power by retaining information the release of which would enable others to do what it does.” | 同上，**p. 221** | 按原意改写旁白：“靠捂住某些信息来守住权力，这些信息一旦放出去，别人也能干它的活。”**不说**这是 Hickson 对维修工的解释 |
| 中心性：工作流的渗透度与“一停就马上、严重地影响主流程”（immediacy） | 同上，pp. 221–222 | “你一停，整条线马上受影响” |
| 三个条件“each necessary but not sufficient” | 同上，p. 222 | “缺一个都不灵” |
| Hickson 等人自己分析过克罗齐耶这家厂：维修工难以替换“很可能”有工会协议的因素；这份权力“得三条一起解释，不能只靠不确定性” | 同上，**p. 225**（“it is likely that union agreements ensured…”；“has to be explained on all counts and not by uncertainty alone”） | 新增一句旁白，保留“很可能” |
| 维修一旦写成标准程序，替代者就看得见、找得到（planned maintenance 会提高可替代性） | 同上，p. 224 | 第七段推论里引用为“希克森他们也是这么分析的”，结论部分仍标“推论/可以想见” |
| «Le pouvoir réside donc dans la marge de liberté dont dispose chacun des partenaires engagés dans une relation de pouvoir, c'est-à-dire dans sa possibilité plus ou moins grande de refuser ce que l'autre lui demande.» | Crozier & Friedberg, *L'Acteur et le système*, Seuil, 1977, **pp. 59–60**（初版页码；Points 版页码二手文献作 69–70，未核） | 法文全句上屏（不念），旁白讲白话意思 |
| «ce qui est incertitude du point de vue des problèmes est pouvoir du point de vue des acteurs» | 同书，约 p. 21（由 OCR 分页推定） | 新增一句：从事情的角度看是不确定性，从人的角度看就是权力。法文上屏，不标页码 |
| zone d'incertitude：书中没有一句话的定义；核心表述在 pp. 61–62（权力取决于一个人能控制的、与别人行动能力相关的不确定区域有多大） | 同书 | 旁白给白话解释，不当作逐字定义 |
| 四种权力来源（专长与职能专门化 / 与环境的关系 / 对沟通与信息的掌握 / 组织的一般规则） | 同书，**p. 71** | 照说 |
| 维修工的两难：机器坏得太勤、生产完全停摆，这张牌也就废了（作者自称“推到极端”的说法） | 同书，**p. 67** | 新增，旁白明说“推到极端的说法，不是说故意搞破坏” |
| 1977 年书中重提维修工：“用各种办法保住修理方面的能力垄断”、对车间主任的“攻击性” | 同书，约 p. 52 | 支撑“门道只留在他们自己脑子里” |
| 规章的“潜在功能”：最大限度保住参与者的自主（即尽量减少直接的人身依附），并使其免于面对面的冲突 | Friedberg, “Introduction to the Transaction Edition”（2010 年再版，导言署 2009 年 3 月），**p. xii** | 照说，归到 Friedberg 2010 年导言 |
| 恶性循环：直接的、私人的依附“格外难受”→ 要求更多规章来管住这些“临时解决问题的人”→ 更多规章、更僵 | 同上，**p. xi** | 照说 |
| “生产工人要更多科层制，维修工要保住阴影区” | **不在** Friedberg 导言里（导言没提生产工人、维修工、阴影区） | 片中只说“有研究者把它概括成一句话”，不挂 Friedberg 的名字 |

## 三、配音里的外语

- 英文两句由克隆声音直接念，ASR 回读通过。
- 法文：克隆声音念 “zone d'incertitude / cercle vicieux”，ASR 分别听成 “Zone de Dense Attitude”“Circle V-shue” 等，**判定不合格**，按规矩不念，只上屏。
