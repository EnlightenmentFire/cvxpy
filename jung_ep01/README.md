# 荣格精读 01《你说的内向，不是荣格说的内向》

微信视频号竖屏视频（1080×1920，30fps，约 4 分 55 秒）的全部源文件。画面由浏览器逐帧渲染，旁白用开源 TTS 本地合成，底乐由代码合成。

| 文件 | 作用 |
|---|---|
| `script.py` | 逐句旁白稿（也是字幕来源），注释里标了每句是原文 / 大意 / 解读 / 例子 |
| `SOURCES.md` | 每一句引文的出处、原文和核对情况；素材与许可 |
| `out/旁白稿.md` | 带时间码的可读版旁白稿 |
| `video.html` `base.css` `engine.js` `diagrams.js` | 画面：场景、版式、逐帧动画引擎、三个示意图 |
| `tts.py` | Kokoro-82M v1.1-zh 逐句合成，输出旁白和时间轴（`build/timeline.json`） |
| `music.py` | 合成氛围底乐并与旁白混音（旁白处自动压低） |
| `render.js` | 用 Playwright/Chromium 逐帧截图并编码 |
| `build.sh` | 一键重建成片 |

改稿流程：改 `script.py` 的文字 → `./build.sh`。画面上各元素的出现时间用 `data-in="L12c1"` 这种写法绑定到“第 12 句第 2 个小句”，旁白变了画面会自动跟着对拍。换音色：`VOICE=zf_099 ./build.sh`。

字体（思源宋体/黑体、EB Garamond，均 OFL）和模型权重体积大，没有入库；`build/` 是中间产物。
